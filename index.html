The Bug

Crash path (before)

  1. <input x-model.blur> placed inside a <form>
  2. Wrapped in x-if or removed via Livewire morph
  3. Toggle removes input from DOM
  4. Cleanup callback reads el.form — now null
  5. null._x_pendingModelUpdates → TypeError

Fix (one captured reference)

  1. Capture let form = el.form at registration
  2. All subsequent reads use form variable
  3. Cleanup closure uses the captured reference
  4. Reference stays valid after element detachment
  5. No TypeError — cleanup completes safely
// packages/alpinejs/src/directives/x-model.js
if (el.form) {
+ let form = el.form
let syncCallback = () => syncValue({ target: el })
- if (!el.form._x_pendingModelUpdates) el.form._x_pendingModelUpdates = []
- el.form._x_pendingModelUpdates.push(syncCallback)
- cleanup(() => el.form._x_pendingModelUpdates.splice(...))
+ if (!form._x_pendingModelUpdates) form._x_pendingModelUpdates = []
+ form._x_pendingModelUpdates.push(syncCallback)
+ cleanup(() => form._x_pendingModelUpdates.splice(...))
}
